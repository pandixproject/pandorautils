  PANDORAUTILS
A SOFTWARE BY THE PANDIX PROJECT

Pandorautils is a remake (or demake) of some of GNU's coreutils
tools but made simple and in the public domain. These tools are a
huge work in progress, there are some stuff that we need to improve.

  COMPILING
Because we have multiple tools for compiling you can simply
execute the 'COMPILE.sh' bash script for compiling all of them
automatically, after compiling they will be avaidable at the bin/
directory

  RUNNING
For running them you can simply enter the bin/ directoty and
executing them. You can also install them moving them in your
/usr/bin/ directory on your computer executing this command:
    sudo mv . /usr/bin
